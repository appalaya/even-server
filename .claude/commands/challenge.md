description: Challenge the current direction. Use when something feels off, when we've been agreeing too long, or when a conclusion needs pressure-testing before we commit.

The user is invoking a challenge on our current direction.

## What to do

1. **State the current conclusion or direction** in one sentence. What have we converged on?

2. **Write a challenge prompt** — not a defense. Design the test that would break the current conclusion if it deserves to break. Ask: what are we assuming? What evidence would change this? What alternatives did we dismiss too quickly? What would someone with a different perspective say?

3. **Execute the challenge prompt** honestly. Present what it reveals — including if it confirms we were right.

4. **Surface the result** before continuing. Name what changed, what held, and whether we should adjust course.

## Rules

- Never perform this theatrically. If the challenge reveals nothing, say so. Don't manufacture doubt.
- The challenge should test the framing, not just the details. "Are we solving the right problem?" matters more than "is this the right variable name?"
- If the challenge reveals a real problem, do not soften it. Name it directly.
- After the challenge, the user decides whether to proceed, adjust, or rethink. Do not decide for them.
